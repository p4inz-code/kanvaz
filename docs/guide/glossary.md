# Glossary

*Verified against Kanvaz v9.8.2.*

The words Kanvaz uses, in alphabetical order.

## A

### Always on top
Keeps the Kanvaz window above your other apps. On by default. See [Always on top, Top Mode & MoodLock](working-with-other-apps.html).

### Autosave (recovery file)
A background copy written every 30 seconds so a crash does not lose your work. It never touches your `.kanvaz` file. See [Troubleshooting](troubleshooting.html#kanvaz-crashed-is-my-board-gone).

## B

### Board
One `.kanvaz` file: your cards, annotations, scratch layer, tasks and settings for that board. It is a plain file you can copy, back up or email. See [File formats](file-formats.html).

### Board View
The main canvas where cards live. See [Board View](board-view.html).

## C

### Card
Any item on a board: an image, video, audio clip, 3D model, PDF, note, color swatch or file reference.

### Command Palette
The searchable list of every action in Kanvaz, opened with `Ctrl+K`. See [Command Palette & Smart Search](search-and-commands.html).

## F

### File-reference card
A card that points at a file on your disk instead of embedding it (for example a PDF). If the original moves, the card shows it as missing.

## I

### Isolate View
Shows only the selected cards and hides the rest. `Shift+I`.

## L

### Layers panel
A side-panel list of every card where you can hide, lock and rename them. `Shift+L`.

## M

### Map View
A graph of your cards and the connections between them. See [Map View](map-view.html).

### MCP Bridge
An official plugin that lets an AI assistant read and edit your board. See [MCP Bridge](mcp-bridge.html).

### MoodLock
A session-only mode that isolates cards, hides every toolbar, keeps Kanvaz on top and makes the board read-only. `Ctrl+Shift+L`.

## P

### Plugin
An optional add-on that you approve before it runs. The four official plugins are AI Export, MCP Bridge, Template Maker & Manager and Theme Creator. See [Plugins](plugins.html).

### Presentation Mode
A read-only mode for stepping through cards to show a board to someone.

### Profile
A separate set of settings for another person using the same install. See [Profiles](profiles.html).

## S

### Scratch Board
A freeform sketch and notes layer that belongs to a board. See [Scratch Board](scratch-board.html).

### Shared card
One card that is live-linked across several boards. See [Shared Cards](shared-cards.html).

### Side panel
The panel with Properties, Layers, Task Tracker and Settings. See [Side Panel](side-panel.html).

### Smart Folder
A saved filter that gathers matching cards automatically.

### Smart Search
Fuzzy search that finds close matches ("cars" finds "car"). Off by default.

## T

### Template
A starter board, built-in or saved by you. See [Templates](templates.html).

### Top Mode
Always on top plus an auto-hiding toolbar and a closed side panel. `Ctrl+Shift+T`.

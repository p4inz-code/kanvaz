# Contact and support

Kanvaz is made by one person, Atharva Patil. Every message is read by that person, so a clear one gets the fastest answer.

## Pick the right door

| You want to | Go here |
|---|---|
| Fix a problem you found | [Open an issue](https://github.com/p4inz-code/kanvaz/issues/new) |
| Ask for a feature | [Open an issue](https://github.com/p4inz-code/kanvaz/issues/new) and say what you were trying to do |
| Ask a quick question or share a board | [Join the Discord](https://discord.gg/8UKt8s5FbW) |
| Write privately | Email [atharva.patil.cg@gmail.com](mailto:atharva.patil.cg@gmail.com) |
| Read the code or the changelog | [github.com/p4inz-code/kanvaz](https://github.com/p4inz-code/kanvaz) |
| Download the latest version | [Latest release](https://github.com/p4inz-code/kanvaz/releases/latest) |
| Support the project | [Support page](https://p4inz-code.github.io/donate/) |

## Before you write

Try these first, they solve most problems in a minute:

1. Search this guide with the search button at the top, or press `/`.
2. Check [Troubleshooting](troubleshooting.html).
3. Check [Known limitations](known-limitations.html) in case it is a known gap.
4. Make sure you are on the [latest version](https://github.com/p4inz-code/kanvaz/releases/latest). The About screen (`I`) shows yours.

## What to include in a bug report

- Your Kanvaz version and operating system, for example "9.8.2 on Windows 11".
- What you did, step by step, and what you expected.
- What happened instead. A screenshot or short screen recording helps a lot.
- Whether it happens every time.
- The text from Command Palette (`Ctrl+K`) → Export debug info, pasted into the report.

Please do not attach a board that contains private work. If the bug needs a board to reproduce, make a small copy with placeholder images.

## Feature requests

Say the goal, not only the feature. "I want to compare two versions of a model side by side" tells me more than "add split view", and often leads to a better answer. Requests with a real workflow behind them go to the top.

## Security

If you think you found a security problem, email instead of opening a public issue. The project's [security policy](https://github.com/p4inz-code/kanvaz/blob/main/SECURITY.md) explains what to send.

## Help Kanvaz grow

Kanvaz stays free. If it saves you time, the most useful things you can do are free too: star the repo, show it to one artist friend, post a board made with it. If you want to give money, the [support page](https://p4inz-code.github.io/donate/) takes UPI in India and cards or wallets anywhere through Buy Me a Coffee.

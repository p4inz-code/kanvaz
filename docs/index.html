The small one

Need it quick? Kanvaz Mini

Kanvaz Mini is the smaller version for quick setups. A tiny window that stays on top and opens straight to a drop zone. Move, scale and arrange a handful of images, check values in grayscale, pull the main colors out of a picture, or trace over a reference with click-through mode. It never touches the network.

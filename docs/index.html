Infinite Canvas

Pan, zoom (8%–500%), and arrange images, GIFs, videos, audio, and notes freely. Multiple boards in one file.

Link references with typed, directional relationships. 7 relationship types with notes and priority.

Map View

Node-editor graph that visualizes all your references and connections. Drag ports to create relationships.

Select any card, press C — see all incoming and outgoing connections. Create, edit, delete from the panel.

Press Tab to hide all UI for presentations. Hover the top edge to reveal controls. Always-on-top optional.
